# App Flow — Daniel Beni Portfolio

## 1. Global flow

```text
LANDING
  ↓
HERO
  ↓
IDENTITY
  ↓
SELECTED WORK
  ↓
WHAT I BUILD
  ↓
EXPERIMENTS
  ↓
COMMUNITY
  ↓
ABOUT
  ↓
CONTACT
```

---

## 2. First visit

```text
Visitor opens site
      ↓
Hero animation
      ↓
Immediate identity recognition
      ↓
Scroll invitation
      ↓
Selected work
```

The visitor should never have to hunt for what Daniel does.

## 8. HUGO flow — future

```text
HUGO
 ↓
Question
 ↓
Intent detection
 ↓
Knowledge retrieval
 ↓
Answer
 ↓
Suggested related topic
```

Example:

```text
Visitor:
"What is GBLRecover?"

HUGO:
"GBLRecover is a Revenue Assurance platform
developed during Daniel's CAMTEL internship..."
```

The assistant should never invent facts.

---

## 9. Error flow

If GitHub API fails:

```text
GitHub unavailable
↓
Use cached/static data
↓
Site remains functional
```

If contact API fails:

```text
Form unavailable
↓
Show email CTA
↓
No dead end
```

---

## 10. Reduced-motion flow

```text
prefers-reduced-motion
       ↓
disable non-essential transitions
       ↓
retain hierarchy
       ↓
retain content
```

## 11. Mobile flow

1. identity

3. capabilities
4. experiments
5. community
6. contact

Navigation remains accessible at all times.
